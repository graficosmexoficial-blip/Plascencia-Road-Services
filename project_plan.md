# Angel's Paint & Autobody Website Rebuild

## 1. Project Description
Rebuild of Angel's Paint & Autobody official website — a professional auto body and paint shop based in Zebulon, North Carolina. The site serves as a marketing landing page to attract customers seeking collision repair, dent removal, bumper repair, paint jobs, and headlight restoration. Target audience is vehicle owners in Zebulon and surrounding North Carolina areas.

## 2. Page Structure
- `/` - Home (full landing page with all sections)
- `/about` - About Us (planned for future phase)
- `/services` - Services detail page (planned for future phase)
- `/contact` - Contact page (planned for future phase)

## 3. Core Features
- [ ] Dark-themed responsive homepage with video hero
- [ ] Estimate request form in hero section
- [ ] Stats bar with key business metrics
- [ ] About Us section with image and trust badges
- [ ] Services showcase with cards
- [ ] Performance metrics / Why Choose Us section
- [ ] How It Works 4-step process
- [ ] Customer reviews / testimonials
- [ ] Contact CTA sections
- [ ] Footer with navigation, services, contact info, and map embed

## 4. Data Model Design
No database required for this phase — static marketing website with form submissions handled via Readdy forms.

## 5. Backend / Third-party Integration Plan
- Supabase: Not required for Phase 1
- Shopify: Not required
- Stripe: Not required
- Forms: Readdy form submission for estimate requests

## 6. Development Phase Plan

### Phase 1: Homepage Rebuild
- Goal: Rebuild the complete homepage with all sections from the original site
- Deliverable: Fully styled, responsive homepage matching the reference design

### Phase 2: Additional Pages
- Goal: Build About Us, Services, and Contact pages
- Deliverable: Three additional pages with consistent styling and navigation

### Phase 3: Polish & SEO
- Goal: Add animations, refine interactions, and enhance SEO
- Deliverable: Production-ready site with smooth UX and complete metadata
